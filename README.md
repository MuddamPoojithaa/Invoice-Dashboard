Invoice Dashboard 🌟

A comprehensive Invoice Dashboard built with PHP, JavaScript, and MySQL for efficient invoice management and payment tracking.

Features

✅ Dynamic invoice generation with automatic client details

✅ Real-time dashboard stats: pending, paid, and partial payments

✅ PDF invoice creation for professional documentation

✅ Advanced search & filter by month, year, client, and status

✅ User-friendly interface for smooth workflow

This project emphasizes automation, accuracy, and usability, streamlining financial operations for businesses.
